# Scripting Scripts

Scripting 脚本的非官方维护副本和自动更新包。

## 安装

点击项目名下载 `.scripting` 文件，并使用 Scripting 打开：

- [镜花水月](https://raw.githubusercontent.com/cc166/scripting-scripts/main/releases/%E9%95%9C%E8%8A%B1%E6%B0%B4%E6%9C%88.scripting)
- [和风天气](https://raw.githubusercontent.com/cc166/scripting-scripts/main/releases/%E5%92%8C%E9%A3%8E%E5%A4%A9%E6%B0%94.scripting)
- [快递小助手](https://raw.githubusercontent.com/cc166/scripting-scripts/main/releases/%E5%BF%AB%E9%80%92%E5%B0%8F%E5%8A%A9%E6%89%8B.scripting)
- [Github规则更新](https://raw.githubusercontent.com/cc166/scripting-scripts/main/releases/Github%E8%A7%84%E5%88%99%E6%9B%B4%E6%96%B0.scripting)
- [panel](https://raw.githubusercontent.com/cc166/scripting-scripts/main/releases/panel.scripting)
- [CLS Telegraph](https://raw.githubusercontent.com/cc166/scripting-scripts/main/releases/CLS%20Telegraph.scripting)
- [Colorful Clouds](https://raw.githubusercontent.com/cc166/scripting-scripts/main/releases/Colorful%20Clouds.scripting)
- [书源阅读](https://raw.githubusercontent.com/cc166/scripting-scripts/main/releases/%E4%B9%A6%E6%BA%90%E9%98%85%E8%AF%BB.scripting)
- [Pickup Code](https://raw.githubusercontent.com/cc166/scripting-scripts/main/releases/Pickup%20Code.scripting)
- [Launch](https://raw.githubusercontent.com/cc166/scripting-scripts/main/releases/Launch.scripting)
- [中國聯通](https://raw.githubusercontent.com/cc166/scripting-scripts/main/releases/%E4%B8%AD%E5%9C%8B%E8%81%AF%E9%80%9A.scripting)
- [项目历史管理器](https://raw.githubusercontent.com/cc166/scripting-scripts/main/releases/%E9%A1%B9%E7%9B%AE%E5%8E%86%E5%8F%B2%E7%AE%A1%E7%90%86%E5%99%A8.scripting)

已安装脚本每 10 分钟检查一次 `main` 分支中的对应更新包。发布版本以各项目 `script.json.version` 为准。
