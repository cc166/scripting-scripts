# Scripting Scripts

用于备份和维护 Scripting 脚本的私有仓库。

## 说明

仓库包含原创脚本，以及基于公开脚本调整和维护的版本。第三方脚本的版权和许可归原作者及原项目所有，使用时请遵守对应许可与服务条款。

仓库不保存账号、凭据或私人配置。
