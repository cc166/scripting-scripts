# 网上国网

国家电网电费、阶梯进度与近期用电趋势小组件。此目录是基于上游项目的非官方改造版。

## 运行

1. 安装并启用与 `api.wsgw-rewrite.com` 对应的网上国网请求重写。
2. 在网上国网 App 中打开电费相关页面，让重写获取账户数据。
3. 运行脚本设置页，点击“获取账户列表”。
4. 添加中号小组件。多户号时，在小组件参数中填写 `0`、`1`、`2`……选择账户。

## 设置

- 显示户名
- 柱状图天数
- 阶梯按年累计或按月计算
- 柱状图颜色、主题色、浅色/深色主题
- 阶梯阈值与刷新间隔
- 真实数据/演示数据预览
- 仅清除项目数据缓存，不删除设置

## 数据口径

年度阶梯用电量按群内确认的口径计算：已结算年度电量 `totalEleNum` 加当前月每日用电量合计。接口不返回每日用电量时保留已结算年度电量。
