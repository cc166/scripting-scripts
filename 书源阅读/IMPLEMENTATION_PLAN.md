# 书源阅读 下一阶段实现计划

## 当前现状

当前脚本已经具备可运行的阅读 MVP：

- 独立脚本目录、`script.json`、`index.tsx`、`widget.tsx`
- 书源本地存储、内置书源、导入书源
- 搜索书籍、查看目录、进入正文阅读
- 最近阅读恢复
- 阅读设置：主题、字号、行距、字体、颜色
- 基础缓存：目录缓存、章节缓存
- 试源调试页
- 规则兼容子集：`gutendex`、`htmlRule`
- `htmlRule` 当前支持：`CSS / XPath / JSONPath / POST / headers / nextContentUrl / replaceRegex`

当前已经完成的增强项：

- 书架、阅读历史、继续阅读直达
- 阅读进度记录
- 目录倒序、目录 sheet、正文重载
- 离线缓存整本、缓存管理
- 书源管理页、试源重试
- 阅读设置增强：段间距、页边距、首行缩进、正文对齐
- Widget 展示书架/进度摘要

当前阶段已经不再继续扩找书源，后续重点转向“完整阅读器能力”和“原生 iOS 体验”。

## 产品目标

把当前 MVP 推进为一个更完整的书源阅读器，覆盖这四条主线：

1. 阅读主流程完整
2. 书架与历史可管理
3. 书源管理与调试更可靠
4. UI 和交互更接近原生 iOS 阅读器

## 非目标

当前阶段暂不追求：

- 完整兼容全部 Legado 规则
- 验证码、登录态、复杂反爬、加密解密的站点特化适配
- 多端云同步

## 优先级路线

## P0：把阅读器主流程补完整

这是最优先的一层，完成后脚本会从“可演示”变成“可长期使用”。

- 书架
  - 支持加入书架
  - 支持移出书架
  - 支持显示在读、收藏、历史
- 阅读进度
  - 记录书籍级和章节级进度
  - 记录最近一次阅读时间
  - 继续阅读时优先直接进入上次章节
- 目录体验
  - 支持目录倒序
  - 支持快速跳章
  - 支持当前章节高亮
- 阅读体验
  - 完善底部上一章/下一章栏
  - 支持正文重载
  - 支持目录入口
  - 支持沉浸式阅读信息层级优化
- 缓存
  - 明确区分目录缓存与正文缓存
  - 增加缓存清理入口
  - 增加简单的缓存失效策略

## P1：把“书源阅读”做成真正可维护的工具

- 书源管理
  - 支持删除自定义书源
  - 支持启用/停用书源
  - 支持书源分组和基础筛选
  - 支持重复书源识别
- 试源与调试
  - 展示更明确的失败阶段
  - 增加原始规则摘要
  - 增加请求参数摘要
  - 增加一键重新试源
- 阅读记录
  - 最近阅读扩展为阅读历史列表
  - 展示每本书最近阅读到哪一章
- Widget
  - 与首页视觉一致
  - 更明确展示当前在读
  - 根据尺寸裁剪信息密度
- 阅读统计
  - 记录每日阅读时长
  - 支持设置每日阅读目标
  - 提供单独统计页查看每日完成情况
  - 增加更有氛围感的激励元素，例如连续达标、今日徽章、进度文案

## P2：扩规则兼容面

- 扩 `htmlRule` 的兼容能力
  - 更完整的 XPath 子集
  - 更完整的 JSONPath 子集
  - 更灵活的字段清洗
  - 更稳定的分页正文拼接
- 扩导入映射
  - 更多 Legado 字段映射
  - 更清晰的导入错误提示
- 请求层增强
  - 超时与重试策略
  - 更细的 header/cookie 支持
  - 基础会话维持能力

## P3：高级产品能力

- 离线下载
  - 支持整本缓存
  - 支持下载状态展示
  - 支持删除已下载内容
- 阅读个性化
  - 页边距
  - 段间距
  - 首行缩进
  - 对齐方式
  - 更多主题预设
- 书架体验
  - 置顶
  - 分组
  - 搜索
  - 最近更新提示
- 阅读氛围与留存
  - 阅读时长趋势
  - 连续阅读天数
  - 每日目标达成可视化
  - 更有氛围感的小组件或首页摘要

## UI / 交互专项

这一条贯穿所有阶段，但优先跟随 P0 一起推进。

- 首页
  - 坚持 `List + Section` 的原生风格
  - 强化“搜索 / 继续阅读 / 书架 / 书源”主路径
  - 压缩说明性文案
- 阅读页
  - 继续降低顶部信息噪音
  - 优化底部翻章栏状态
  - 增加目录与设置的阅读期入口
- 目录页
  - 更适合长目录浏览
  - 当前章节更突出
- 试源页
  - 保持阶段化结构
  - 让“哪里失败了”更一眼可见

## 数据结构计划

后续建议逐步补这些核心数据模型：

- `bookshelfItems`
  - 书架书籍、来源、最近阅读时间、收藏状态
- `readingHistory`
  - 历史记录列表，而不是单个最近阅读
- `readingProgress`
  - 书籍级、章节级进度
- `cacheMetadata`
  - 缓存大小、更新时间、失效时间
- `readingStats`
  - 每日阅读时长、连续阅读天数、目标完成情况
- `readingGoal`
  - 每日目标时长、提醒文案、展示开关

## 建议的实施顺序

1. 先做阅读统计、每日目标、统计页
2. 再做书架体验增强和首页摘要优化
3. 再做缓存/下载状态的细化
4. 然后继续扩书源管理与调试细节
5. 最后再继续扩规则兼容面
